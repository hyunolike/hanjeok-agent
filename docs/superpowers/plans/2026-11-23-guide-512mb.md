# 512MB Guide Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. The user approved implementation; execute inline with an isolated final reviewer.

**Goal:** 외부 DB와 NVIDIA 임베딩을 사용하는 512MB용 안내 API 제공.
**Architecture:** 기존 API/에이전트 계약을 유지하고 임베딩과 그래프 연결을 구성으로 선택한다. 별도 잠금 의존성과 Docker 이미지로 HTTP 경로만 배포한다.
**Tech Stack:** Python 3.13, FastAPI, LangGraph, Neo4j Python driver/GraphRAG, httpx, SQLite.
**Spec:** docs/superpowers/specs/2026-11-23-guide-512mb-design.md

## Global Constraints

- 1024차원, NVIDIA만 사용, 로컬 실행 호환, SSE 계약 유지.
- API 컨테이너에는 Neo4j 서버와 torch 모델을 넣지 않는다.
- 실제 외부 호출/적재/배포를 fixture 검증과 구분한다.

## Review Focus

- 차원만 같은 서로 다른 모델의 벡터가 섞이는 경우 준비되지 않음으로 닫는다.
- 임베딩 응답의 누락/중복 인덱스, NaN, 0 벡터를 거부한다.
- SSE 연결 해제와 실행 예외 뒤에 질문 슬롯이 새지 않는다.
- 같은 방문의 동시 질문이 체크포인트를 덮어쓰지 않는다.
- 의존성 설치만 가벼워지고 실제 import는 무거워지는 문제를 이미지에서 확인한다.
